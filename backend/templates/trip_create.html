Dispatch guide

Recording an emergency response

Use recorded information only. GreenRoute does not invent units, crew or live positions.

  1. Identify the incident. Name the response, choose the emergency type and set the priority used by the register.
  2. Set the route. Enter the incident location and the receiving destination. Add intermediate stops only when they are part of the response.
  3. Calculate the route. Address lookup uses OpenStreetMap and OSRM. If the services are unavailable, the response can still be saved without a route estimate.
  4. Review and create. The reference and incident reference are generated by the server. The record appears immediately in the response register.
